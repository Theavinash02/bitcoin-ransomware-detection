# Feature groups

Generated by `ransomdet features`. Runtime 85.7 s, peak memory 2097 MB.

Kept groups: B (ratios), C (dollar value), D (round amounts), E (same-day percentiles). A group is kept when adding it to the 6 base features raises validation PR-AUC or recall at 0.1% FPR by more than 0.002. Chosen feature set (21 features): `length`, `weight`, `count`, `looped`, `neighbors`, `income`, `avg_payment_btc`, `count_per_neighbor`, `income_usd`, `log_income_usd`, `round_usd_50`, `round_usd_100`, `round_usd_500`, `round_btc_0.1`, `round_btc_0.5`, `round_btc_1`, `round_min`, `pct_income_usd`, `pct_count`, `pct_neighbors`, `pct_length`.

Everything here is scored on validation (Jul-Dec 2016). The test years are not used. Thresholds are set on validation itself, so recall at the FPR target is a ranking comparison, not a forecast.

Groups: A = log1p of income_btc, count, neighbors, length. B = income / neighbors (average payment) and count / neighbors. C = income in dollars at that day's close. D = distance of the dollar and BTC income to round amounts. E = rank among all addresses on the same day, read from per-day quantile tables saved to `data/processed/day_quantiles.parquet`. Trees split on order only, so group A changes a LightGBM model only through feature sampling and binning.
